## US-104: Retake / False-Start Deduplication — COMPLETED
- Created src/autovideo/dedup.py as a deterministic pre-pass between segmentation and LLM classification
- Retake detection: difflib.SequenceMatcher on normalized adjacent segment text (threshold 0.75) to find near-duplicate clusters
- Best-take selection: heuristics prefer longest segment ending with sentence boundary (duration + 2.0 bonus for [.!?…])
- False-start detection: regex patterns covering "let me start over", "wait, let me rephrase", "actually, let me redo", "scratch that", "no, that wasn't right"
- Enrichment: adds retake_cluster_id, is_best_take, false_start, dedup_reason metadata to segments.json in-place
- Integration: classify.py applies _apply_dedup_overrides() after LLM validation to force-cut flagged segments, ensuring deterministic retake handling feeds into cut_list.json
- Pipeline updated: transcribe → segment → dedup → classify → assemble → validate
- Unit tests in tests/test_dedup.py: normalization, similarity, false-start patterns, retake cluster detection, best-take selection, run() integration for false starts, retake clusters, and no-op case
- 170 tests passing; mypy and ruff clean
